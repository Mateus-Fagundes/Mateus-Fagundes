### Sobre mim

Desenvolvo interfaces **modernas, responsivas e pensadas para quem usa**.

Meu foco é unir código limpo com **psicologia de UX/UI**: hierarquia visual, carga cognitiva, feedback e microinterações que fazem a pessoa entender a tela sem precisar pensar.

E uma interface boa precisa ser encontrada: **SEO, GEO, AEO e VSO** entram no projeto desde o início, não depois do deploy.

- Layout moderno do mobile ao ultrawide
- Decisões de design guiadas por comportamento, não por achismo
- Performance e acessibilidade como parte do design, não como extra
- Visibilidade em buscadores, IAs generativas e assistentes de voz desde o layout

### Princípios que levo a sério

#### Experiência

| Princípio | Na prática |
|---|---|
| **Lei de Hick** | Menos escolhas por tela, decisões mais rápidas |
| **Lei de Fitts** | Alvos de toque grandes onde o polegar alcança |
| **Hierarquia visual** | O olho sabe para onde ir antes de ler |
| **Feedback imediato** | Toda ação tem resposta visível em menos de 100 ms |
| **Consistência** | Padrões previsíveis reduzem a carga cognitiva |

#### Ser encontrado

| Princípio | Na prática |
|---|---|
| **SEO** | HTML semântico, Core Web Vitals e dados estruturados |
| **GEO** | Conteúdo claro e citável por IAs generativas (ChatGPT, Gemini, Perplexity) |
| **AEO** | Respostas diretas que viram snippet e resposta pronta |
| **VSO** | Linguagem natural pensada para busca por voz |
